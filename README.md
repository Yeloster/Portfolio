# Personal Portfolio

My personal portfolio website, built to showcase my projects, technical interests and development progress.

**Live website:** [yeloster.github.io/Portfolio](https://yeloster.github.io/Portfolio/)

## About

This website serves as a central place to showcase my work in software development and computing, alongside my interests in cybersecurity and aerospace technology.

The portfolio will develop over time as I build and document more projects.

## Built With

- HTML
- CSS
- Git and GitHub
- GitHub Pages

## Features

- Responsive portfolio website
- Project cards showing development status
- About and contact sections
- Custom 404 error page

## Project Status

The website is live and under active development. Some projects listed on the site are planned and have not yet been completed.

## Running Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Yeloster/Portfolio.git
   ```

2. Open `index.html` in a browser, or use a local development server such as VS Code Live Server.

## Deployment

The website is hosted using GitHub Pages and published from the `main` branch.

Changes pushed to the branch are published automatically by GitHub Pages.
